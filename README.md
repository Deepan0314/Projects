# 🍔 Burger Shop Website

A modern and responsive Burger Shop web application built using React.js.  
This project showcases an interactive food ordering interface with smooth animations, responsive layouts, and reusable UI components.

---

## 🚀 Features

- 🍔 Interactive burger menu
- 🛒 Add to cart functionality
- 📱 Fully responsive design
- ✨ Smooth animations and transitions
- 🔍 Product browsing interface
- 🎨 Modern UI/UX design
- ⚡ Fast performance using Vite
- ♻ Reusable React components

---

## 🛠 Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Tailwind CSS
- Framer Motion
- Lucide React Icons

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/burger-shop.git
```

Navigate to project folder:

```bash
cd burger-shop
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
